# Сетевой режим станции

Обновление сглаживания и проверок: [MOTION.md](MOTION.md).

Из корня outputs/horizon, два отдельных терминала:

```powershell
cargo run --manifest-path station/Cargo.toml -p station-server --locked -- --listen 127.0.0.1:7777
cargo run --manifest-path station/Cargo.toml -p station-client --locked -- --connect 127.0.0.1:7777
```

Второго игрока запускайте ещё одним клиентом с тем же адресом.
Для другого компьютера в локальной сети сервер запускается с `--listen 0.0.0.0:7777`,
клиент — с `--connect IP_КОМПЬЮТЕРА_СЕРВЕРА:7777`. На сервере нужен доступ к TCP-порту 7777.
Без `--connect` клиент по-прежнему запускает локальную игру.

В лобби каждый выбирает профессию и нажимает «Готов». Отсчёт начинается, когда готовы все подключённые игроки.
Первый подключённый игрок — ведущий: он завершает раунд и возвращает игру в лобби.
При его отключении права получает самый ранний из оставшихся участников.
Вход во время раунда разрешён; новый игрок прибывает ассистентом с ID-картой.
Профессии, комплекты и доступы: [CREW.md](CREW.md).

## Что реализовано

- До 8 соединений, отдельные персонажи, руки, слоты и длительные действия.
- Общие Rapier-физика, предметы, ящик, воксельная карта и раунд.
- Сервер назначает идентификатор; клиент не выбирает чужого персонажа.
- Проверки расстояния, владения предметом, эпохи раунда и прав ведущего.
- Отключение освобождает предметы и удаляет персонажа. Повторный вход создаёт нового.
- Неизменившаяся карта повторно не передаётся и не перестраивается на клиенте.
- Чужие персонажи используют общий спрайт станции.
- При потере связи клиент показывает сообщение; повторное подключение — перезапуском.

## Устройство и ограничения

`server/src/net.rs`: отдельный TCP-сервер и клиентский адаптер; `sim/src/actors.rs`:
контексты игроков поверх одной симуляции. Существующий локальный Session сохранён.
Протокол Station v13: длина u32 big-endian и JSON-пакет с версией. Максимум 4 МиБ,
ограничены число соединений, буферы и число обрабатываемых сообщений за такт.
Медленный клиент не блокирует сервер. Тайм-аут сервера 10 с, клиента 5 с.
Симуляция работает на 60 Гц, ввод применяется сервером; добавлены клиентское сглаживание и предсказание движения: см. MOTION.md.

Сеть Horizon изучена (`horizon-client/src/game/integrated.rs`,
`horizon-protocol/src/connection.rs`): она обслуживает Minecraft-пакеты и объекты.
Для станции добавлен самостоятельный протокол, а не подключён Minecraft login/play.
Аккаунтов, шифрования, сохранения личности после переподключения и автоматического
проброса портов нет. Это рабочий прототип для локальной/доверенной сети.
