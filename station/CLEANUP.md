# Очистка Minecraft-контента — 23 ноября 2026

Из рабочей папки отправлены в корзину Windows 15,944 файлов (4.10 ГБ),
сгруппированных в 76 целей. Это размер удалённых из папки данных;
место на диске освободится после очистки корзины. Корзина автоматически не очищалась.
Полный перечень путей и размеров: CLEANUP.json.

## Убрано

- docs/media: скриншоты Minecraft и старое оформление документации Horizon.
- launcher/docs и launcher/assets: иллюстрации старого лаунчера, реклама Sculk,
  изображение блока травы и логотипы Minecraft-загрузчиков.
- Скриншоты Minecraft из benchmarks; численные отчёты и код оставлены.
- Пять наборов tools/fixtures: Minecraft-датапаки и пример рецепта echo shard.
- .local/parity-runner: временные данные проверки совместимости с Minecraft.
- Корневой target: кэш сборки исходного Horizon. Кэш station/target сохранён.
- Дублирующий checkout Horizon в work, включая его собственную историю Git.
  Основной репозиторий outputs/horizon и его история Git сохранены.
  work/rust-anything и work/ss14 сохранены для проверок переноса.

## Сохранено

- Исходный код Horizon, включая Minecraft-совместимые системы, и код станции.
- Шрифты с отдельными лицензиями, общие пиктограммы, элементы управления,
  небольшие интерфейсные текстуры JEI под отдельной лицензией и иконки упаковки.
  Они не являются набором ванильных текстур Minecraft и нужны для сохранённого кода.
- Все лицензионные уведомления, SS14-исходники проверок и результаты работы станции.
- Историческая техническая документация; ссылки на удалённые локальные картинки
  убраны в четырёх Markdown-файлах (CLEANUP-DOCS.json).

Стартовый README теперь описывает станцию. В сохранённом коде лаунчера удалена
рекламная панель; обложки и иконки Minecraft заменены ссылками на существующий
нейтральный значок Horizon. Новых картинок не создано. Полный старый лаунчер
не собирался: проверены форматирование и существование встроенных файлов.

После очистки файлов JAR, MCA, pack.mcmeta, OGG и WAV в рабочей области
(за исключением .git и кэшей компиляции) не найдено. Это проверка типов файлов,
а не утверждение об отсутствии всех упоминаний Minecraft в оставшемся коде.
История Git основного проекта намеренно не переписывалась: прежние файлы могут
оставаться в старых коммитах. Удалённые тестовые датапаки больше не доступны
старым parity-скриптам Horizon; при необходимости их можно восстановить из Git.
